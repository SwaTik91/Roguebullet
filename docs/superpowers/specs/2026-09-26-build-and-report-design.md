# Экран билда и отчёт по бою

Дата: 2026-09-26. Второй этап, часть C: показать игроку его сборку прямо в бою и разобрать забег после него. Новых боевых механик нет — только видимость того, что уже происходит.

## 1. Подсчёт урона

У каждого источника урона ставится метка оружия: `gun`, `laser`, `scatter`, `grenade`, `emp`, `orb`, `drone`, а также `resonance` для резонанса форм. Метод `damage` складывает фактически нанесённый по здоровью урон в `run.dmgByWeapon[tag]`. Через метку проходят и производные источники: взрывы (`explode`), веерный взрыв (`shapeBlast`), лужи (`pool.tag`), горение (`enemy.burnTag`), осколки (`burstPellets`), бомбы пуль и дронов.

Пули несут свою метку в поле `tag`, выставленное при создании: пулемёт и рой — `gun`, дробь и осколки — `scatter`, заряд — `grenade`, дрон — `drone`. Луч и горение от него — `laser`. EMP-разряды и цепь — `emp`. Орбиты, отражение и вспышка щита — `orb`. Резонанс форм — `resonance`.

Урон по ядру в счётчик не идёт: считаем только урон по врагам. Счётчик ни на что в бою не влияет, только копит числа.

## 2. Экран билда (пауза)

В бою рядом с кнопкой скорости появляется кнопка «Билд». Нажатие ставит бой на паузу — игровой цикл замирает — и показывает оверлей поверх поля. Кнопка «Продолжить» снимает паузу. Оверлей ничего не выдаёт и не шлёт на сервер.

Содержимое компактное:

- по каждому оружию из забега: название, уровень, выбранная ветка (если есть);
- взятые карты, сгруппированные по оружию;
- надетые запчасти;
- сводка: урон пулемёта, шанс крита, HP ядра, состояние овердрайва.

Пока открыт билд, стрельба, спавн и таймеры стоят. Пауза недоступна на выборе карты и после боя.

## 3. Отчёт после боя

На экране результата (смерть или полное прохождение) над кнопками появляется блок «Отчёт по бою»:

- полоски и проценты урона по оружию из `run.dmgByWeapon`, резонанс отдельной строкой;
- всего убийств, длительность забега, достигнутый уровень и волна;
- взятые карты по порядку;
- «слабое звено» — оружие забега с наименьшей долей урона.

На экране конца отдельного уровня (не конец забега) отчёта нет.

## 4. Аналитика и статистика

Событие `run-end` получает поле `damage` — доли урона по оружию за забег (0..1). Сервер хранит их в `run_events` и в сводке `/stats/summary` отдаёт среднюю долю урона по каждому оружию за период. Забеги тестера в сводку не входят. Страница `/stats/` показывает среднюю долю урона по оружию рядом с остальными метриками.

## Проверка

- Урон каждого оружия попадает в свою метку; сумма долей близка к 1.
- Кнопка «Билд» ставит паузу, «Продолжить» снимает; на выборе карты и после боя кнопка недоступна.
- Отчёт показывает доли урона, слабое звено и метрики забега только в конце забега.
- `run-end` несёт доли урона; сводка отдаёт среднюю долю по оружию без имён и без забегов тестера.
